# Contributing

Thanks for your interest in extending this benchmark.

## Adding new humanizer data

1. Fork the repo
2. Test additional humanizers on your own essay corpus following the methodology in `docs/methodology.md`
3. Append rows to `data/benchmark_results.csv`
4. Open a pull request with your batch ID and detector versions

## Suggesting a humanizer to test

Open an issue with the tool name, pricing, and a link. I'll add it to the Q4 2026 backlog.

## Reporting inaccurate data

If your reproduction of the benchmark produces significantly different numbers, please open an issue with your detector API build dates and essay characteristics.
